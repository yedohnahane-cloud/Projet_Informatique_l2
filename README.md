# JavaMastery AI

Plateforme web d'apprentissage du langage Java intégrant une IA pour accompagner les étudiants dans leur progression.

> Projet réalisé en équipe en Licence 2 Informatique à Aix-Marseille Université.

## Fonctionnalités

- Authentification (connexion/inscription)
- Cours de Java structurés
- Quiz avec progression (80 % requis)
- Chatbot IA (Google Gemini)
- Suivi des progrès
- Jeux pédagogiques

## Technologies

- Django (Python)
- HTML • CSS • JavaScript
- SQLite
- Google Gemini API



## Équipe

Projet développé en équipe selon la méthode Scrum.
